# 🎓 College Management System

A dynamic, full-stack web application designed to streamline campus admission workflows, manage visitor inquiries, and handle trial forms efficiently. Built as a modern alternative to static campus portals.

---

## 🚀 Live Demo
- **Frontend Live URL:** [https://college-management-web.vercel.app/](https://college-management-web.vercel.app/)

---

## ✨ Features

- **Visitor Inquiry & Lead Management:** Capture and track prospective student inquiries seamlessly.
- **Trial Form Submissions:** Handle interactive trial/application forms submitted by prospective visitors.
- **Admission Management:** Organize and process admission-related requests in one centralized system.
- **Responsive UI:** Clean, minimal, and user-friendly interface optimized for all devices.

---

## 🛠️ Tech Stack

**Client (Frontend):**
- React.js
- HTML5 / CSS3 / JavaScript (ES6+)
- Tailwind CSS / Modern CSS

**Server (Backend):**
- Node.js
- Express.js

**Database:**
- MongoDB / Mongoose

**Deployment:**
- Frontend deployed on **Vercel**
